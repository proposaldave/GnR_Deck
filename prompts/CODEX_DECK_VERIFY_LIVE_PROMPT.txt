Use Local mode.

Goal: determine what is actually live for the Give n Receive deck without making content edits.
Codex owns the trace. Dave should only need to provide the requested edit or branch.

RULES
- Do not edit deck content.
- Do not merge, reset, delete, force push, or clean.
- Do not assume browser cache equals publish failure.
- Prefer source evidence before visual debugging.

CHECKS
1. Confirm branch, clean/dirty state, local HEAD, origin/main, and remote main.
2. Confirm GnR_deck.html and index.html exist and whether their hashes match.
3. Check raw GitHub source for main/index.html.
4. Check GitHub Pages source at:
   https://proposaldave.github.io/GnR_Deck/
   and cache-busted:
   https://proposaldave.github.io/GnR_Deck/?v=[short-commit-hash]
5. If Dave reports a missing visible edit, locate the requested text/element in local source, raw GitHub source, and Pages source.
6. Verify whether the target slide ID is active through SLIDE_ORDER, SLIDE_ALTS, or STAFF_ORDER.
7. For visible text edits, identify the exact active selector/DOM line that renders the old text and verify that exact selector/DOM line changed. Do not treat the edit as live because the replacement appears elsewhere.
8. If needed for a visual/layout issue, open/render the active visible slide and compare against the source.

MISSING-SLIDE TRACE
- If Dave reports a slide disappeared, treat it as a deck regression until proven otherwise.
- Search current source and recent history for the missing slide by visible text, slide ID, nearby comments, and screenshot context.
- Compare current `SLIDE_ORDER` against recent published commits and branch diffs to identify when the slide left active order.
- Classify whether the slide is still in HTML but missing from `SLIDE_ORDER`, moved to `SLIDE_ALTS`, moved to `APPENDIX_ORDER`, moved to `TRASH_ORDER`, deleted from HTML, or hidden by render/state.
- If the slide is still in source and the restore is obvious, the next action is to restore its active registry entry and update shifted `SLIDE_ALTS`, not to ask Dave to find the branch.
- If `SLIDE_ORDER` changed, run or recommend `tools/verify_slide_order_guard.ps1` and report added/removed active slide IDs.

FAILED-EDIT PHRASE TRACE
- If Dave says "didn't I ask..." or names a visible phrase, trace the phrase across all local deck/* branches, not only checked-out worktrees.
- Search by exact old text, likely replacement text, nearby slide ID, and screenshot context.
- Identify the original active selector/DOM line for the visible text before deciding whether the edit is live.
- Use branch content and branch diffs:
  `git grep -n -i "<visible phrase>" <branch> -- GnR_deck.html`
  `git diff $(git merge-base main <branch>) <branch> -- GnR_deck.html`
- If a local branch contains the requested change but it is not in origin/main, classify as `skipped branch` and identify the branch.
- If the branch intent is tiny and safe, the next action is to publish/port that exact intent, not to ask Dave to find the branch again.
- If the replacement text exists somewhere else but the original active selector/DOM line still contains the old text, classify as `wrong selector` and the next action is to repair that exact selector.

TRACE REQUIREMENT
- Given a requested edit or branch, trace:
  request
  branch
  commit
  active slide source
  index.html mirror
  pushed main
  live cache-busted URL
  rendered visible result
- If a branch is not merged, identify whether it was skipped, conflicted, risky, or never published.
- If source contains the change but render does not, identify whether the slide is hidden, inactive, behind an alt rail, or visually overridden.

CLASSIFY THE ISSUE
- cache: raw GitHub and cache-busted Pages have the change, canonical browser view is stale.
- source not published: local or raw source lacks the change.
- inactive variant: change exists only in retained/deleted/appendix/stale HTML, not active registry path.
- skipped branch: change exists only on an unmerged branch.
- conflict: branch was not merged because it conflicts.
- wrong slide: edit landed on a different active slide/slot than Dave requested.
- wrong selector: replacement text landed in a nearby element, eyebrow, duplicate, alt, comment, or hidden source while the original active visible selector stayed unchanged.
- missing slide: slide exists in history/source but is absent from the active registry path.
- rendered hidden: source exists but visible render hides, covers, or does not reach it.
- request ambiguity: requested target cannot be mapped to one active slide/section.
- browser state: browser tab/session is stale even though cache-busted source is current.
- visual mismatch: source contains the change but rendered layout does not match intent.
