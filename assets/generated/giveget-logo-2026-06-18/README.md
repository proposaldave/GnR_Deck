# GiveGet Logo Batch

Date: 2026-06-18

DECISION: These are actual vector logo lockups, not generated brand imagery. The image model is useful for mood and scenes; the logo needs exact text, reusable geometry, and deterministic output.

## Files

- `00-giveget-logo-board.svg` - comparison board
- `giveget-mark-only.svg` - standalone return-loop mark
- `giveget-logo-primary.svg` - primary logo plus tagline
- `giveget-logo-horizontal-tagline.svg` - wider deck/site lockup with deck line
- `giveget-logo-stacked.svg` - stacked lockup with spoken support and close copy

## Recommended Direction

Use `giveget-logo-primary.svg` as the default.

Use `giveget-mark-only.svg` only as an icon/avatar.

Use `giveget-logo-horizontal-tagline.svg` when the deck line needs to be visible:
Give more to your community. Get more from it.

Use `giveget-logo-stacked.svg` for a closing slide or brand one-pager.

## Copy

Company/logo: GiveGet
Spoken: Give n Get
Tagline: Where what you give comes back.
Deck line: Give more to your community. Get more from it.
Close: Give more to your community. Get more back. That's GiveGet.
